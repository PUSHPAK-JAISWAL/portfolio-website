# Security Policy

## 🔒 Supported Versions

We actively support and maintain the latest release of this project.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🛡️ Reporting a Vulnerability

We take the security of this repository seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

1. **Do not disclose the issue publicly** through GitHub Issues, Discussions, or social media.
2. **Email the maintainer directly**:
   - Contact: **Pushpak Jaiswal**
   - Email: **[pushpakmjaiswal@gmail.com](mailto:pushpakmjaiswal@gmail.com)**
   - Subject line: `[SECURITY] Vulnerability in portfolio-website`

### Information to Include in Your Report:

- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue (proof-of-concept code, scripts, or screenshots).
- Any recommended mitigations or fixes.

---

## ⏱️ Response Timeline

- **Initial Acknowledgement**: You will receive an acknowledgement within **48 hours** of report receipt.
- **Assessment & Triage**: An assessment of the impact and severity will be conducted within **5 business days**.
- **Fix & Disclosure**: Once a fix is verified, a release will be published, and appropriate credit will be given (unless anonymity is requested).

---

## 🤝 Responsible Disclosure & Bounty

This is a personal open-source developer portfolio project. While we do not offer monetary bug bounties, we are deeply grateful to researchers who report vulnerabilities responsibly and will publicly acknowledge your help in the release notes.
